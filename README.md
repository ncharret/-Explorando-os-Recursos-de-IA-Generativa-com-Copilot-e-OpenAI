# Laboratório: Copiloto e Ferramentas da OpenAI

Este repositório documenta o uso de ferramentas de inteligência artificial, com foco no Copiloto (GitHub/Microsoft) e nos serviços da OpenAI, como ChatGPT e DALL·E.

## Objetivo

Explorar o potencial da IA generativa na criação assistida, utilizando:
- Geração de código
- Escrita automatizada
- Geração de imagens
- Restrições e filtros de conteúdo

## Entregável

Este repositório contém:
- Exemplos de prompts aplicados
- Casos de uso práticos
- Anotações e aprendizados adquiridos
